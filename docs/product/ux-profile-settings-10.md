Имя trim-ится; пустое становится null. Не выдумывать обязательность, максимальную длину
или новые ошибки валидации. ViewModel проверяет доступность аватара и защищает от повторного
сохранения. Выбор титула/оформления также проверяет isUnlocked. Ошибка записи не должна

код не предоставляет полноценного состояния ошибки сохранения.

Тексты приватности/о приложении не превращены в фиктивные ссылки. Термин «Приватность»
сокращает слишком длинный заголовок при 320 px / 150%; действующей политики в коде нет.

Нативные действия ведут на явно обозначенную границу 108:238. Figma не открывает разрешения,
не проверяет pending requests и не подтверждает доставку. После возврата приложение должно
refresh-ить платформу. Сохраняются экспериментальная природа, зависимость от ОС, местное
время и отмена сегодняшнего напоминания после занятия. Это отличается от UTC-дней статистики.
Полное состояние кнопок и соответствие controller должны проверяться при реализации;
specimens не заменяют все комбинации native-state.

## XP, ранги, достижения и персонализация

Источники: PlayerProgress, records, DailyTrainingProgress, practice history, ProfilePreferences.
Не считать all-time по ограниченному списку видимых сессий.

| Возможность | Реальное условие / ограничение |
| --- | --- |
| XP / уровень | 1 правильный ответ = 1 XP; level = floor(totalXp / 500) + 1; остаток XP показывать отдельно от total |
| Ранг | Группа пяти уровней, индекс ограничен текущим массивом восьми рангов. Список: 1–5 Новичок … 36–40 Легенда. Уровни выше 40 не получают выдуманного нового ранга. |
| Первое занятие | completedTrainings ≥1 либо текущий план завершён; свободная игра не подменяет план |
| 1 000 правильных ответов | totalCorrectAnswers ≥1000 |
| 7 дней подряд | practice history → sevenDayStreakEarned; прогресс = min(bestRecordedStreakDays, 7). Loading/error не показывать как 0; ошибка имеет существующий retry. Границы истории и будущие даты сохраняют пояснения. |
| Мастер памяти | ≥3 distinct mode среди records Number Sprint и Memory Grid, именно текущий расчёт; не считать количество сессий или Custom variants |
| Скрытое достижение | Всегда Hidden; реализованного условия открытия нет |
| Титул «Начинающий» | Доступен сразу |
| «Мастер внимания» / аватар «Фокус» | Уровень ≥10 |
| «Быстрый взгляд» | Рекорды в ≥4 разных режимах Wide Eye |
| Аватар «Молния» | Уровень ≥20 |
| Фон «Сумерки» | Уровень ≥15 |
| Стандартные аватар, рамка, фон | Доступны сразу |
| Рамка «Исследователь» | isUnlocked=false всегда. Метаданные обещают 10 тренировок, но это не работающий unlock. Показывать недоступность; исправление механики — отдельная задача. |
| Недавние открытия | Только подтверждённые условия перехода из recentProgress, максимум три; не заполнять вымышленными событиями |

## Проверка и границы прототипа

Просмотрены статические renders: профиль новичка, настройки, редактор, EN/KK 390×844,
RU/KK 320×640 с текстом 150% и полным scroll, dark, 800×1100 (контентная колонка 560 px).
Исправлены фиксированная высота длинного заголовка, наследованная подпись поля Input,
слишком длинный заголовок приватности и одинокая стрелка при переносе.
Compact использует боковой отступ 16; увеличен текст, а не весь viewport.

Структурный аудит проверяет локальные destinations, цели нажатия ≥48×48, ширину текста
относительно родителя и отсутствие IMAGE fills. Нет сломанных локальных переходов,
слишком маленьких активных целей и текста шире родителя. Нет UI-растров.

Home/Catalog/Progress получили URL-мосты в настройки; Progress — в новый/накопленный профиль.
Переходы внутри страницы заданы reactions. Основной возврат настроек ведёт в Прогресс;
**контекстный возврат к каждому источнику URL-мостом не эмулируется**. В реализации Back
обязан сохранить исходный раздел, scroll и выбор. Корневой bottom bar во вложенных страницах скрыт.

Сценарии статические: ввод произвольного имени, состояние после перезапуска, последовательные
комбинации предпочтений, выбор оформления через разные входы и полный перевод всех вложенных
страниц не эмулируются. Выбор EN/KK показывает переведённый корень настроек и соответствующий
выбор языка; остальные вложенные страницы пока RU. Новые награды не выдаются переходами.
Loading/retry не заменены искусственным успехом. Presentation viewer вручную не проходился.

Это экспертная проверка, не пользовательское тестирование. EN/KK — проект текстов без
языковой редактуры. Screen reader, keyboard focus, IME, системный Back, смена языка в runtime,
платформенный font scaling и доставка/разрешения напоминаний остаются **непроверенными**.
Gradle/unit/Roborazzi не запускались: diff содержит только документацию, продуктовый UI не изменён.
